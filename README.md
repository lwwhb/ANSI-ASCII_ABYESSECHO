# 深渊回响 (Abyss Echo)

> *在无尽的深渊中，你将何去何从？*

一款基于浏览器的 Roguelike 地牢探险游戏，使用 ANSI/ASCII 艺术风格渲染，配以程序化生成的 8-bit 芯片音乐。

## 🎮 游戏特色

- **5大生态群落** — 石质地牢 / 水晶溶洞 / 远古陵墓 / 熔岩核心 / 虚空深渊，各具独立生成算法与专属机制
- **30+种敌人 + 5个Boss** — 独特AI行为与特殊能力
- **完整物品系统** — 武器、护甲、戒指、护符、药水、卷轴、食物，含鉴定与诅咒机制
- **3种职业** — 战士 / 法师 / 游侠，各有专属技能与天赋
- **程序化生成** — 5种独立地牢算法，每次游戏独一无二
- **8-bit 芯片音乐** — 9首场景BGM + 12种增强音效，程序化实时合成
- **天赋系统** — 每3级3选1，深度定制角色成长
- **商店与随机事件** — 探索中的意外惊喜与交易
- **成就与传承** — 15个成就，死亡后装备传承给下一个角色
- **暂停存档** — 每层自动保存，可暂停退出后继续，死亡即删档

## 🚀 快速开始

```bash
cd abyss-echo
npm install
npm run dev
```

## 🛠️ 技术栈

- **React 19** + **TypeScript 6** + **Vite 8**
- **Zustand 5** 状态管理
- **Web Audio API** 音频合成
- **Canvas API** 地图渲染
- **SeededRandom** (Mulberry32) 确定性随机数
