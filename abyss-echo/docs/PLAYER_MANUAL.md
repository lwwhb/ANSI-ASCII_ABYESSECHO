# 🎮 深渊回响 (Abyss Echo) - 玩家手册

> *在无尽的深渊中，你将何去何从？*

---

## 📖 游戏简介

**深渊回响** 是一款基于浏览器的 Roguelike 游戏，使用 ANSI/ASCII 艺术风格渲染。你扮演一名坠入无尽深渊的探险者，在程序生成的地牢中不断向下深入。死亡即终局，每次都是全新的旅程。

**核心目标：** 尽可能深入深渊，击败强大的Boss，在排行榜上留下你的名字。

## 🎹 操控指南

### 移动
| 按键 | 功能 |
|------|------|
| `↑↓←→` / `WASD` / `HJKL` | 移动 |
| `空格` / `.` | 等待一回合 |

### 交互
| 按键 | 功能 |
|------|------|
| `,` | 拾取脚下物品 |
| `>` | 在楼梯上下楼 |

| `P` | 打开商店（站在商店格上时） |
| `?` | 显示帮助 |
| `M` | 显示手册 |
| `ESC` | 暂停并退出（保存进度） |

### 技能
| 按键 | 功能 |
|------|------|
| `Z` | 技能1 |
| `X` | 技能2 |
| `C` | 技能3 |

> 技能消耗MP，使用后进入冷却。不同职业拥有不同技能。

### 背包内操作
| 按键 | 功能 |
|------|------|
| `↑↓` | 选择物品 |
| `U` | 使用物品 |
| `E` | 装备物品 |
| `D` | 丢弃物品 |
| `I` / `ESC` | 关闭背包 |

### 升级时
| 按键 | 功能 |
|------|------|

## ⚔️ 职业选择

### 🗡️ 战士 (Warrior)
- **核心属性：** 高STR、高VIT
- **初始HP：** 30 + VIT×3 | **初始MP：** 5 + INT×2
- **定位：** 近战肉盾，高伤害高血量
- **适合：** 新手玩家，正面冲锋型打法
- **颜色：** 🔴 红色
- **技能：** 盾击（击退并眩晕相邻敌人2回合，8MP，3回合CD） / 战吼（防御+5持续5回合，12MP，8回合CD） / 旋风斩（攻击周围所有敌人1.5倍伤害，15MP，6回合CD）

### 🔮 法师 (Mage)
- **核心属性：** 高INT
- **初始HP：** 15 + VIT×3 | **初始MP：** 25 + INT×2
- **定位：** 魔法输出，高MP但身躯脆弱
- **适合：** 喜欢策略性打法的玩家
- **颜色：** 🔵 蓝色
- **技能：** 火球术（发射火球造成范围伤害，10MP，4回合CD） / 冰盾（防御+5且冰冻免疫5回合，8MP，6回合CD） / 闪电链（对最近3个敌人释放闪电，15MP，5回合CD）

### 🏹 游侠 (Rogue)
- **核心属性：** 高DEX
- **初始HP：** 20 + VIT×3 | **初始MP：** 10 + INT×2
- **定位：** 闪避暴击，攻守兼备
- **适合：** 喜欢灵活走位的玩家
- **颜色：** 🟢 绿色
- **技能：** 暗影步（瞬移到最近敌人身边2倍暴击，8MP，4回合CD） / 毒刃（下次攻击附剧毒5伤害/4回合，6MP，3回合CD） / 扇刃（2格内所有敌人伤害，12MP，5回合CD）

## 🎵 音频系统

游戏全程配备程序化生成的8-bit芯片音乐，无需下载任何音频文件。

### 背景音乐
游戏会根据场景自动切换BGM，无需手动操作：

| 场景 | 音乐风格 |
|------|----------|
| 标题画面 | 神秘琶音（C小调，90BPM） |
| 石质地牢 1-5F | 行进节奏 + 鼓点（C小调，120BPM） |
| 水晶溶洞 6-10F | 空灵三角波（E小调，110BPM） |
| 远古陵墓 11-15F | 肃穆锯齿波（D小调，100BPM） |
| 熔岩核心 16-20F | 激烈驱赶 + 鼓点（E弗里吉亚，130BPM） |
| 虚空深渊 21F+ | 诡异不谐和声（C减调，80BPM） |
| Boss战 | 快速琶音 + 密集鼓点（C小调，140BPM） |
| 商店 | 轻快三角波（F大调，100BPM） |

战斗、拾取、开门、升级、治疗等操作都有对应的8-bit音效反馈。

## ⚔️ 战斗系统

### 基础规则
- **回合制：** 你行动一步，所有敌人也行动一步
- **近战：** 走向敌人自动攻击，伤害 = STR + 武器 - 敌人DEF
- **伤害显示：** 攻击消息会拆分显示物理伤害和元素伤害，如"造成 6 + 3🔥火 点伤害"
- **暴击：** 5% + DEX/200 的概率，造成1.5倍伤害（致命一击天赋：额外+50%暴击伤害）
- **防御：** 减少 DEX/3 + 护甲DEF 的伤害
- **技能暴击：** 技能也有 5% + DEX/300 的暴击率，受致命一击天赋加成
- **MP回复：** 每回合自动回复 max(1, floor(INT/5)) MP

### 元素系统
| 元素 | 克制 | 被克 |
|------|------|------|
| 🔥 火 | 克制冰、毒 | 被冰克制 |
| ❄️ 冰 | 克制火 | 被火克制 |
| ⚡ 雷 | 克制无弱点敌人 | — |
| 🟢 毒 | — | 被火克制 |

**元素克制：** 1.5倍伤害 | **抵抗：** 0.5倍伤害

### 状态效果
| 效果 | 持续 | 效果 |
|------|------|------|
| 🟢 中毒 | 每回合 | 持续受到毒素伤害（消息中显示具体伤害和持续回合） |
| 🔴 灼烧 | 每回合 | 受到火焰伤害 |
| 🔵 冰冻 | 跳过回合 | 无法行动 |
| 🩸 流血 | 每回合 | 持续受到流血伤害 |
| 🟡 混乱 | 跳过回合 | 50%概率随机方向移动（对敌人同样生效） |
| 🛡️ 防御增强 | 持续 | 额外防御加成 |
| 🗡️ 毒刃 | 一次性 | 下次攻击附加剧毒（5伤害/4回合） |

### 鉴定系统
- 拾取的**药水**和**卷轴**初始未鉴定
- 未鉴定物品显示为"红色药水"、"灼热的纸卷"等
- **使用**该物品即可鉴定，效果也会同时生效
- ⚠️ 未鉴定的药水可能是有毒的！
- 鉴定卷轴(`?`)可以安全鉴定一个未鉴定物品

### 诅咒系统
- ⚠️ 某些装备可能带有**诅咒**
- 诅咒装备无法卸下或丢弃
- 诅咒装备属性降低（武器伤害-2，护甲防御-2，戒指/护符加成归零）
- 名称显示 **[咒]** 标记（鉴定后可见）
- **解咒卷轴** 可移除所有物品的诅咒
- 诅咒装备可以**以1/4价格出售**（推荐：与其等解咒卷轴，不如出售腾出背包空间）

## 💰 经济系统

### 金币
- 击败敌人获得金币（Boss掉落更多）
- **贪婪天赋** 可使金币掉落增加50%

### 商店
- 探索中有概率遇到流浪商人（商店格 `$`）
- 按 `P` 键打开商店界面
- **购买：** 以原价购买商品
- **出售：** 以半价出售背包中的物品（诅咒物品以1/4价格出售）

## 💾 暂停存档系统

### 核心原则：存档 = 暂停，不是存档点

深渊回响采用 **Suspend Save**（暂停存档）机制，这是经典 Roguelike 的正统做法。存档的唯一目的是"暂停游戏"，不允许通过反复读档来降低难度。

### 自动保存
- 每次下楼梯时自动保存当前进度
- 保存内容包括角色状态、地图、敌人、物品、楼层等全部游戏数据

### 暂停退出
- 在游戏中按 `ESC` 键，弹出确认对话框
- 确认后保存进度并返回标题画面
- 下次打开游戏时可选择"⏎ 继续冒险"恢复

### 加载即删档
- 选择"继续冒险"加载存档后，**存档立即删除**
- 这意味着你只有一次机会继续，无法通过反复读档来重试不利的局面
- 如果关闭页面后重新打开，存档仍在，直到你选择继续游戏

### 死亡删档
- 角色死亡时存档自动删除，**无法恢复**
- 死亡画面显示"☠️ 永久死亡 — 存档已删除，无法回溯"提示
- 死亡界面展示冒险总结（角色、等级、楼层、击杀、金币等），成就和排行榜通过按钮查看
- 这是 Roguelike 的核心体验：每次决策都是不可逆的

### 存档损坏
- 如果存档数据损坏（极少发生），系统会自动删除损坏的存档
- 标题画面会显示"⚠️ 存档损坏或已丢失"提示

## 💡 策略指南

### 🆕 新手建议

1. **选战士开局** — 高HP容错率大，适合熟悉游戏机制
2. **优先拾取食物** — 饥饿比敌人更致命
3. **不要贪心** — HP低时及时用药水，不要冒险
4. **开门小心** — 门后可能有敌人埋伏
5. **注意鉴定** — 使用前先想想药水可能是毒药
6. **留意诅咒** — 装备前考虑是否值得冒险，诅咒装备无法卸下

### 🏅 进阶技巧

1. **利用走廊** — 在窄道中1v1，避免被包围
2. **元素克制** — 火焰武器对冰/毒系敌人效果拔群
3. **节约药水** — 完全治疗药水留到Boss战
4. **合理分配属性** — 战士优先STR/VIT，法师优先INT，游侠优先DEX
5. **善用卷轴** — 地图卷轴可以帮助规划路线
6. **技能搭配** — 战士盾击+旋风斩连招，法师冰盾+闪电链，游侠暗影步+毒刃
7. **商店策略** — 金币有限，优先购买高稀有度装备

### 🐉 高手心得

1. **BOSS战术** — Boss每5层出现一次，确保满状态再下楼
2. **天赋选择** — 致命一击+元素亲和是DPS核心，急速恢复+冥想是续航保障
3. **装备搭配** — 戒指+护符的属性加成可以叠加
4. **暴击流** — 高DEX + 致命一击天赋 + 游侠 = 暴击率极高
5. **每日挑战** — 相同种子可以重复练习，研究最优路线
