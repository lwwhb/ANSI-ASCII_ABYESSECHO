# 五系统融合设计规格：遗物·强化·事件·元素·主题房间

> 版本：v1.0 | 日期：2026-05-23
> 核心体验：每局构建差异化 | 地图方向：主题房间+叙事空间
> 设计思路：空间叙事×构建涌现（思路A改良版）

---

## 1. 整体架构

### 1.1 五系统关系

主题房间是空间叙事骨架，承载遗物获取、装备强化、元素连锁素材和事件触发。遗物改规则（质变），强化改数值（量变），事件做选择，元素连锁是空间×战斗的桥梁。

```
                    ┌─────────────────┐
                    │   主题房间(空间)  │ ← 叙事骨架
                    │   Themed Room   │
                    └───────┬─────────┘
                            │ 承载
              ┌─────────────┼─────────────┐
              │             │             │
     ┌────────▼───┐  ┌─────▼──────┐  ┌──▼─────────┐
     │  遗物系统   │  │  事件系统   │  │ 元素连锁   │
     │  (规则改写) │  │  (选择代价) │  │ (空间×战斗) │
     └─────┬──────┘  └─────┬──────┘  └──────┬─────┘
           │               │                │
           └───────────────┼────────────────┘
                           │ 强化
                  ┌────────▼────────┐
                  │  装备强化系统    │ ← 金币出口+构建放大器
                  │  (数值定制)     │
                  └─────────────────┘
```

### 1.2 核心设计原则

1. **主题房间是叙事单元**：每个房间有名字、视觉主题、叙事氛围。玩家走过一层，记住的是"那个冰封密室"而非"那个有3个敌人的房间"
2. **概率偏向，不排除**：冰封密室出冰系遗物概率+30%，但仍有其他遗物。杜绝"没火系房间=火系构建废了"
3. **遗物改规则，强化改数值**：遗物是质变（新机制），强化是量变（数字提升）。两者叠加产生"质×量"的构建深度
4. **元素连锁是空间与战斗的桥梁**：主题房间提供元素地形素材，战斗中利用地形触发连锁
5. **自然分层**：基础战斗不看遗物/元素也能通关，但关注这些系统后战斗力指数级增长

### 1.3 与现有系统的层级关系

| 现有系统 | 新系统交互 | 层级 |
|---------|----------|------|
| 天赋(12) | 遗物可以强化天赋效果 | 基础层 |
| Boss祝福(12) | 遗物与祝福产生协同 | 进阶层 |
| 装备特效(9) | 强化放大特效，遗物改写触发条件 | 进阶层 |
| 技能(6类) | 元素连锁改写技能效果 | 深度层 |
| 精英/Boss | 精英掉落遗物，Boss后获得祝福 | 连接点 |

### 1.4 五系统交叉矩阵

|  | 主题房间 | 遗物 | 装备强化 | 元素连锁 | 房间事件 |
|--|---------|------|---------|---------|---------|
| **主题房间** | — | 房间提供遗物获取渠道 | Forge只在特定主题房间 | 地形是连锁素材 | 事件在主题房间触发 |
| **遗物** | 破旧地图揭示房间主题 | — | 铁匠之锤降强化费 | 7个元素遗物改写连锁 | 稀有选项需要遗物数量 |
| **装备强化** | 强化改变房间内战斗难度 | — | — | 强化StatusProc→连锁触发率↑ | 强化作为事件选项 |
| **元素连锁** | 地形元素定义连锁空间 | — | — | — | 事件可改变地形→连锁环境 |
| **房间事件** | — | 事件是遗物主要获取渠道 | 事件可提供免费强化 | 事件可创造/改变地形 | — |

## 2. 主题房间系统

### 2.1 设计目标

给每个房间赋予主题——名字、视觉风格、特定地形配置、叙事文本，让玩家"记住"每个房间。

### 2.4 房间生成规则

1. 每层3-5个主题房间（除起点房间、Boss房间外）
2. 主题从当前生物群落池中随机抽取，不重复
3. 每个主题房间的入口处显示房间名（进入时弹出1行描述文本）
4. 主题房间的地形由主题模板+随机扰动生成，保证每次不同但有辨识度
5. 走廊和普通房间仍然存在，主题房间是特殊标记的房间
6. Boss竞技场、精英房间、商店/事件房间保持不变，主题房间是额外的房间类型

### 2.5 主题房间与元素概率偏向

每个主题房间有元素倾向属性（elementAffinity），影响该房间内遗物掉落的元素概率：
- 匹配元素遗物出现概率×2
- 不匹配但非排斥：正常概率
- 不限制"无元素"遗物：任何主题房间都可能出现

## 3. 遗物系统

### 3.1 设计目标

遗物是永久的被动效果，改写游戏规则而非简单加数值。每局获取不同的遗物组合，让构建产生质变差异。

### 3.2 遗物稀有度与获取

| 稀有度 | 获取渠道 | 每局约获数量 |

| 稀有(Rare) | 精英击杀、稀有事件 | 1-2个 |
| 史诗(Epic) | Boss击杀、隐藏房间 | 0-1个 |

## 4. 装备强化系统

### 4.1 设计目标

允许在Forge（锻造台）花金币强化装备，每件装备最多强化3级，让玩家与装备产生情感联结，同时为金币提供额外出口。

### 4.2 强化机制

| 强化等级 | 费用 | 效果 | 成功率 |
|---------|------|------|--------|
| +1 | 100金 | 基础ATK/DEF+10% | 100% |
| +2 | 250金 | 基础ATK/DEF+20%，特效触发率+5% | 85% |
| +3 | 500金 | 基础ATK/DEF+35%，特效触发率+10% | 60% |

- 失败不损毁装备，只是金币消耗、等级不变
- 铁匠之锤遗物：费用-30%（即+1=70金，+2=175金，+3=350金）
- 熔岩Forge：费用正常，成功后装备获得1层Burn on hit（5%概率附加Burn）
- 虚空Forge：费用减半，但10%概率装备获得Cursed（Cursed效果：ATK-10%，可被Enchant卷轴移除）

### 4.3 强化流程

1. 玩家走到Forge（`⚒`）上，弹出强化选择面板
2. 若无可强化装备（所有装备已+3或无装备），显示提示"没有可强化的装备"，Forge保留不消耗
3. 显示当前装备列表，每件装备显示当前强化等级、下一级费用和效果
3. 玩家选择要强化的装备 → 扣除金币 → SeededRandom判定成功/失败 → 显示结果
4. 一个Forge可使用1次（使用后变为普通Floor）

### 4.4 装备强化与特效的交互

| 特效 | +1效果 | +2效果 | +3效果 |
|------|--------|--------|--------|

## 5. 元素连锁系统

### 5.1 设计目标

让元素之间、元素与地形之间产生连锁反应——观察环境，利用环境。元素连锁是空间与战斗的桥梁。

### 5.2 元素连锁规则

连锁触发条件：**目标同时受到两种可反应的元素影响**（包括地形提供的元素环境）。

| 连锁名 | 触发条件 | 效果 | 视觉 |
|--------|---------|------|------|
| 蒸汽爆发 | Burn敌人+冰系攻击 | 对目标及1格范围内造成ATK×0.8伤害，遮挡视野1回合 | 白色闪烁 |
| 冰封 | Freeze敌人+水地形 | Freeze持续时间+2回合，蔓延至水中所有敌人 | 蓝色扩散 |
| 传导 | 水地形+雷系攻击 | 伤害传导至水中所有敌人（每敌人ATK×0.6） | 蓝色电弧 |
| 毒气燃烧 | 毒雾地形+火系攻击 | 毒雾区域爆炸，造成ATK×1.2伤害+清除毒雾 | 绿→橙闪烁 |
| 腐化放电 | Poison敌人+雷系攻击 | Poison伤害×2，跳转到2格内另一个中毒敌人 | 紫色电弧 |
| 岩浆激活 | Lava地形+火系攻击 | Lava扩散1格（持续2回合后回退） | 红色脉冲 |
| 岩浆凝固 | Lava地形+冰系攻击 | 1格Lava→CooledLava，持续3回合 | 橙→灰 |
| 过载 | 同一敌人连续2次雷系攻击 | 第2次雷系伤害×1.8+Stun 1回合 | 白色闪光 |

### 5.3 地形元素属性

| 地形 | 元素属性 | 可触发的连锁 |
|------|---------|-------------|
| ShallowWater | 💧水 | 冰封、传导 |
| LavaPool | 🌋火 | 岩浆激活、岩浆凝固（反向） |
| CooledLava | 无（可被火系重新激活→Lava） | 岩浆激活 |
| PoisonGas | 🧪毒 | 毒气燃烧、腐化放电 |
| WebFloor | 🕸️物理 | 可被火系点燃→清除+范围Burn |
| SteamVent | 💨气 | 蒸汽爆发（喷发时算作水环境） |
| SpikeTrap | 无 | 冰系攻击可使其"结冰"→3回合无效 |
| CorruptionPool | 🟣虚空 | 不参与元素连锁（虚空元素独立） |
| VoidRift | 🟣虚空 | 不参与元素连锁 |

### 5.4 连锁触发判定流程

```
玩家/敌人使用元素攻击/技能
       ↓
检查攻击范围所有格子：
  - 有元素地形？→ 记录地形元素
  - 目标有元素debuff？→ 记录目标元素
       ↓
查找连锁表：攻击元素 vs 地形/目标元素
       ↓
匹配到连锁？
  → YES: 触发连锁效果，输出消息
  → NO: 正常伤害
```

| 毒腺 | 毒系连锁触发率+20% |
| 元素共鸣 | 连锁触发时ATK+25%（持续2回合） |
| 混沌核心 | 所有连锁伤害×2，自身受25%连锁伤害 |
| 命运编织者 | 连锁触发时获得随机buff |

### 5.6 敌人连锁

敌人也可以触发连锁：
- 火系敌人在ShallowWater旁攻击 → 可能触发蒸汽爆发→伤害玩家
- 增加站位战术重要性——不要站在水边打火系敌人
