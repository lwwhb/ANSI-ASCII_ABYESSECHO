# Boss系统全面重设计 — 设计规格

> 版本: 1.0 | 日期: 2026-05-23 | 状态: 待实现

---

## 一、概述

当前Boss系统的问题：每个Boss只有1个特殊能力、无阶段变化、无机制性挑战、Boss房间无特殊地形。本规格重新设计整个Boss系统，引入多阶段Boss、精英系统、Boss竞技场、隐藏探索元素、楼层氛围描述、Boss祝福。

---

## 二、多阶段Boss系统

### 2.1 核心机制

- 每个Boss拥有3个阶段，由血量阈值触发
- P1: 100%→50%, P2: 50%→25%, P3: 25%→0%
- 阶段转换时：Boss不攻击1回合（给玩家准备时间），消息日志显示阶段切换文字
- 每个阶段解锁新技能，保留旧技能，属性增强

### 2.2 新增字段

```typescript
// Enemy interface
bossPhase: 1 | 2 | 3  // 默认1，仅isBoss=true时有效
```

### 2.3 阶段转换逻辑

在 `processTurn` 敌人行动前检测：
1. 对Boss造成伤害后检查HP百分比
2. HP ≤ 50% 且 bossPhase === 1 → 切换到P2
3. HP ≤ 25% 且 bossPhase === 2 → 切换到P3
4. 切换时：设置bossPhase、修改属性、执行阶段特效（如召唤）、跳过本回合攻击、显示消息

## 三、精英系统

### 3.1 精英敌人

- 每个非Boss楼层有30%概率刷新1只精英怪
- 精英是普通敌人的强化版，名称加前缀"精英"，符号显示金色

| 属性 | 倍率 |
|------|------|
| HP | ×2 |
| ATK | ×1.3 |
| DEF | +3 |
| 经验 | ×2.5 |
| 金币 | ×3 |
| 掉落 | 必定稀有或更好 |

### 3.2 精英词缀

6个词缀，每个精英随机获得1个：

| 词缀枚举 | 名称 | 效果 |
|----------|------|------|
| `EliteArmored` | 铁甲 | 受到物理伤害-30% |
| `EliteFrenzy` | 狂乱 | 每回合ATK+0.5（无上限，被杀时重置） |
| `EliteRegen` | 再生 | 每回合恢复最大HP的5% |
| `EliteVampiric` | 吸血 | 攻击回复造成伤害的30%HP |
| `EliteExplosive` | 爆裂 | 死亡时对周围2格造成ATK×1.5伤害 |
| `ElitePhantom` | 幽影 | 每回合30%闪避攻击 |

### 3.3 新增类型

```typescript
enum EliteAffix {
  Armored = 'armored',
  Frenzy = 'frenzy',
  Regen = 'regen',
  Vampiric = 'vampiric',
  Explosive = 'explosive',
  Phantom = 'phantom',
}

// Enemy interface 新增
isElite: boolean          // 默认false
eliteAffix?: EliteAffix   // 精英词缀
frenzyBonus?: number      // 狂乱累加值
```

### 3.4 精英房间

- 每层40%概率生成1个精英房间
- 入口用铁门封锁，需要主动交互开门
- 房间内1只精英怪 + 2个物品掉落（至少1个稀有或更好）
- 可选择绕过

### 3.5 Boss召唤精英

Boss战P2/P3阶段召唤的小怪有30%概率是精英版：
- 哥布林王P3→精英哥布林（铁甲）
- 蜘蛛女王P3→精英幼蛛（狂乱）
- 深渊之心P2→精英虚空织者（再生）

## 四、Boss竞技场

### 4.1 概述

Boss楼层不再使用普通房间放Boss。Boss房改为特殊竞技场设计，包含不可通过装饰物、可交互物体。

### 4.2 竞技场设计

| Boss | 竞技场特征 |
|------|-----------|
| 哥布林王 | 王座大厅：中央王座(不可通过)，入口处1个可破坏木栏(阻挡逃跑) |
| 蜘蛛女王 | 蛛巢：地面遍布蛛网格(减速1回合)，4角有蛛卵(踩触发生成1只幼蛛) |
| 死亡骑士 | 陵墓正殿：两侧各2个石棺(互动生成骷髅)，中央祭坛(踩上去+3DEF持续3回合) |
| 恶魔领主 | 熔岩竞技场：四角熔岩池(每3回合溢出1格，站上3伤害)，中央1个安全区 |
| 深渊之王 | 虚空圣所：3个虚空裂隙(每5回合随机传送附近的人)，4角虚空柱(攻击破坏后Boss ATK-3) |
| 深渊之心 | 深渊核心：5个虚空柱+中央腐蚀池(每2回合全屏2伤害)+2个治愈水晶(互动回复30%HP一次性) |

### 4.3 新增TileType

```typescript
// 装饰/不可通过
Throne = 'throne'           // 王座（不可通过，阻挡移动）
Barricade = 'barricade'     // 木栏（不可通过，攻击可破坏→Floor）

// 地面效果
WebFloor = 'webFloor'       // 蛛网地面（可走，经过时减速1回合）
SpiderEgg = 'spiderEgg'     // 蛛卵（可走，踩上生成1只幼蛛→Floor）
Sarcophagus = 'sarcophagus' // 石棺（已存在，互动生成骷髅→Floor）——复用现有
Altar = 'altar'             // 祭坛（可走，踩上+3DEF 3回合）
LavaPool = 'lavaPool'       // 熔岩池（不可通过，定期溢出→Lava→CooledLava循环）
VoidRift = 'voidRift'       // 虚空裂隙（可走，定期传送附近实体）
VoidPillar = 'voidPillar'   // 虚空柱（不可通过，攻击可破坏→Floor，破坏后Boss ATK-3）
CorruptionPool = 'corruptionPool' // 腐蚀池（可走，每2回合全屏2伤害）
HealCrystal = 'healCrystal' // 治愈水晶（可交互，回复30%HP后→Floor，一次性）
```

## 六、楼层氛围描述

### 6.1 系统

每次进入新楼层，消息日志首行显示氛围描述。按生物群系和楼层深度变化，25条描述（5个生物群系各5条）+ Floor 30特殊描述1条。

### 6.2 描述内容

#### 石质地牢 (Floor 1-5)

- Floor 1: 潮湿的石壁上渗出冰冷的水珠，火把的光芒在黑暗中摇曳。你的冒险从这里开始。
- Floor 2: 走廊深处传来老鼠的吱吱声，空气中弥漫着陈旧的霉味。
- Floor 3: 墙壁上的抓痕越来越深，似乎有什么东西在黑暗中窥视着你。
- Floor 4: 远处传来金属碰撞的声响，和低沉的、不似人类的笑声。
- Floor 5: 王座大厅的大门就在前方。门后传来号令声和战鼓的节奏——哥布林王在等待。

#### 水晶溶洞 (Floor 6-10)

- Floor 6: 水晶从四面八方生长，折射出诡异的蓝光。地面覆盖着薄薄的冰霜，每一步都发出清脆的碎裂声。
- Floor 7: 洞壁上的水晶脉动如心脏般律动，幽蓝的光芒忽明忽暗。
- Floor 8: 空气中飘浮着微小的冰晶，呼吸间能感到肺部一阵刺痛。
- Floor 9: 细密的蛛网从穹顶垂落，在蓝光中泛着银色的微光。有些丝线上还挂着…不，你不想知道那是什么。
- Floor 10: 一片巨大的蛛网覆盖了整个穹顶，中央的阴影中有什么在缓缓蠕动。蛛丝振动着，像是在迎接猎物。

#### 远古陵墓 (Floor 11-15)

- Floor 11: 石棺整齐地排列在两侧，空气中弥漫着防腐香料的气味。这里安静得令人不安。
- Floor 12: 墓壁上的浮雕描绘着一场古老的战争，战士们的表情永远定格在恐惧之中。
- Floor 13: 地面散落着破碎的骨骸和锈蚀的武器。某些骨骸…似乎在微微移动。
- Floor 14: 黑暗中传来锁链拖地的声音，和低沉的、不似活物的叹息。
- Floor 15: 陵墓最深处，一座巨大的石棺散发着死亡的寒气。棺盖上的骑士浮雕缓缓睁开了眼睛。

#### 熔岩核心 (Floor 16-20)

- Floor 16: 空气灼热得令人窒息，地面裂缝中涌出赤红的岩浆。你感到自己的盔甲在发烫。
- Floor 17: 岩浆河流从墙缝中渗出，空气中弥漫着硫磺的气味。远处传来恶魔的嚎叫。
- Floor 18: 一阵灼热的风暴席卷而过，灰烬落在你的肩头。地面在你的脚下颤抖。
- Floor 19: 恶魔的低语在耳边回响，试图侵蚀你的意志。你的影子似乎不再听从你的动作。
- Floor 20: 炼狱深处，巨大的恶魔端坐在熔岩王座上，双瞳如两团烈焰。"又一个灵魂…来为我燃烧。"

#### 虚空深渊 (Floor 21-25)

- Floor 21: 现实开始扭曲。墙壁在呼吸，地面在脉动，你的手穿过了一张桌子。
- Floor 22: 时间在这里失去了意义。你看到自己的影子在不同方向行走，它们似乎有自己的意志。
- Floor 23: 虚空在吞噬一切——光、声音、记忆。你开始忘记来时的路，但脚步无法停下。
- Floor 24: 维度的裂隙撕裂了空间，你看到另一个自己在裂隙对面，面容扭曲，嘴角上扬。
- Floor 25: 深渊的尽头，一个不属于这个维度的存在注视着你。"你终于来了，回响者。"

#### Floor 30

- 一切归于寂静。没有光，没有暗，没有声音。只有一种不可名状的存在感，像宇宙的心跳。深渊之心在这里等待了亿万年——不是为了毁灭，而是为了被理解。但理解它的代价，是失去自己。

## 七、碑文/剧情碎片系统

### 7.1 概述

每层20%概率出现碑文房。碑文内容按生物群系讲述深渊的历史。收集碑文获得永久小buff。

### 7.2 碑文内容

- 石质地牢："这里曾是王国的地牢，关押着最危险的犯人。直到那个夜晚，地底传来了回响…从此再无人离开。"
- 水晶溶洞："水晶并非天然形成。古帝国的法师们将魔法封印其中，以抵御来自更深处的侵蚀。但水晶在碎裂…"
- 远古陵墓："亡者不愿安息。他们被某种力量唤醒，在永恒的黑暗中游荡。击碎他们的不是死亡，而是希望。"
- 熔岩核心："炼狱之火并非惩罚，而是选择。只有最强大的灵魂才能在烈焰中重塑。其他的，只会化为灰烬。"
- 虚空深渊："深渊不是尽头。深渊是开始。一切从虚空中诞生，一切终将回归。你是回响，还是回响的回响？"

### 7.3 收集奖励

每收集1个碑文 → 永久+1%全属性（跨局存档记录碑文收集数）

### 7.4 新增类型

```typescript
interface Player {
  // ...existing
  inscriptionCount: number  // 碑文收集数
}
```

localStorage 存储碑文收集数，与成就/遗产并列。

## 九、挑战房（可选）

每层8%概率出现挑战房：
- 入口标记："⚠ 此路凶险，但回报丰厚"
- 进入后门锁上，必须击败所有敌人
- 3-4只普通敌人 + 1只精英
- 通关奖励：1个史诗或更好物品 + 大量金币

- 交互纪念碑回顾Boss信息
- 下次到这个楼层时Boss房变为普通房间
